Firebase Authentication Test

This page helps diagnose Firebase authentication issues.

Instructions:

  1. Replace the Firebase config in firebase-config.js with your actual project config
  2. Enable Google Authentication in your Firebase Console
  3. Add your domain to Firebase authorized domains
  4. Run these tests to identify issues

Common Issues:

  • Invalid API Key: Check your Firebase config
  • Unauthorized Domain: Add your domain to Firebase authorized domains
  • Operation Not Allowed: Enable Google provider in Firebase Console
  • Popup Blocked: Allow popups in your browser
